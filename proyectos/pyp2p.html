PY-P2P

A peer-to-peer communication system for file transfer, screen sharing and remote control between computers.

The Concept

Build a tool that enables instant communication between two computers on the same network, without relying on external services or complicated setup.

The Solution

A desktop application with a modern GUI that auto-discovers devices on the network, transfers files of any size, shares your screen in real time and remotely controls another computer.

Capabilities

Key Features

Auto-Discovery

Automatically finds other devices on your WiFi network with no need to type IP addresses by hand.

File Transfer

Send files of any size or entire folders with automatic compression. Drag & drop supported.

Screen Sharing

Share your screen in real time with another user. Ideal for tech support or collaboration.

Remote Control

Take control of the other computer's mouse and keyboard. Perfect for remote assistance.

Built-in Chat

Talk to other users while you transfer files, with modern chat bubbles.

Cross-Platform

Runs on Windows and macOS with native support for system dialogs on both platforms.
