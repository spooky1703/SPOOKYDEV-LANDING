Professor Recommendation

A smart system that turns course enrollment into a decision driven by data, collective experience and NLP algorithms.

The Challenge

ESCOM students face uncertainty when choosing professors during each semester's enrollment, ending up with inefficient schedules or a heavy academic load. The information is usually scattered across unstructured reviews or word of mouth.

The Solution

We built a web platform powered by NLP and smart scraping that collects, analyzes and extracts actionable metrics (quality, difficulty and sentiment) from hundreds of reviews, automating the creation of ideal schedules based on each student's profile.

System Components

Intelligent Architecture

Web Scraping and Fuzzy Matching

An automated collection module focused on extracting information from reviews. It uses fuzzy matching to tolerate variations in professors' names.

NLP and Sentiment Analysis

Text processing that extracts key attributes ("easy to pass", "hard exams") and computes overall sentiment from the reviews.

Schedule Planner

An algorithmic engine that detects course clashes, minimizes excessive gaps and flags overloaded days.

Personalized Recommendation

A multi-criteria system that weighs variables to generate suggestions based on the student's priorities (minimize homework, prioritize learning, etc.).
